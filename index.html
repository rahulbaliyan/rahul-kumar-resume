Project Work

What I've built, and how.

Real-Time Monitoring & Alerting Platform (MUX)

KinesisLambdaAmazon Managed PrometheusGrafanaSQS

The Problem

MUX video streaming metrics needed real-time monitoring so engineering and on-call teams could catch anomalies and system health issues quickly, instead of finding out from users.

The Approach

Built a streaming ingestion pipeline on Amazon Kinesis to process high-volume monitoring events in real time, with AWS Lambda handling event-driven processing and enrichment before data reached the metrics and alerting layer. Amazon Managed Prometheus stored metrics at scale, with Grafana providing real-time dashboards. The alert delivery pipeline ran on Amazon SQS, decoupling alert generation from delivery for reliable, ordered processing of critical alerts.

The Outcome

Real-time visibility into system health for engineering and on-call teams, enabling faster incident detection and response.
